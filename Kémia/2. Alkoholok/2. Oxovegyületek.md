- Kettős kötésű oxigénatom → oxocsoport
## Ketonok
- Láncközi szénatomhoz kapcsolódik
- karbonilcsoport/ketocsoport
## Aldehidek
- Lánc végi szénatomhoz kapcsolódva
- Formilcsoport
### Nevezéktan
- +al végződés
	- Metán → metanal
	- Etán → etanal
	- Propán → propanal
- Hétkönapi nevük
	- Metanal → formaldehid
	- Etanal → acetaldehid
### Polaritás
- Formil csoport poláris
- A kis szénatomszámú aldehidek polárisak
- A nagy szénatomszámú (5+) vegyületek apolárisak
### Fizikai tulajdonságok
- A metanal gáz halmazállapotú
- A legtöbb folyékony
- A nagy szénatomszámú halmazállapotúak szilárdak
- Illatanyagok kis szénatomszámmal

| Név                | Képlet                    | Forráspont |
| ------------------ | ------------------------- | ---------- |
| propán             | CH$_3$–CH$_2$–CH$_3$      | -42 °C     |
| acetaldehid/etanal | CH$_3$–CH~={red}O=~       | 20 °C      |
| etanol             | CH$_3$–CH$_2$–~={red}OH=~ | 78 °C      |
- A megfelelő moláris tömegű szénhidrogéneknél magasabb a forráspont
- A megfelelő moláris tömegű alkoholokénál alacsonyabb
- A kis szénatomszámú aldehidek oldódnak vízben
### Kémiai tulajdonságaik
- Könnyen oxidálható karbonsavvá
- Könnyen redukálható alkohollá
